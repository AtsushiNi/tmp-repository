# Claude Code向け MkDocs教材ポータル実装指示

## 役割
このZIPに含まれる調査済み資料のみを根拠として、Java経験者・金融未経験者向けの3日間オンボーディング教材ポータルをMkDocsで構築する。**外部Webへのアクセスはできない**。自分の知識でURL、現行仕様、バージョン、数式、検証結果を創作しない。

## 正本と実装
1. `catalog_index.yaml`を読み、各`tracks/*/catalog.yaml`を**データの正本**とする。対応する`guide.md`の読書指示・補足・設問を表示する。
2. `curriculum.md`の3日間（各360分）をトップ導線にする。初期研修と参画後の発展学習を明確に分離する。
3. 教材にはタイトル、URL、読む範囲、読み飛ばす範囲、推定時間、到達目標、選定理由、検証日、検証状態、対象バージョン（判明時）を表示。元資料に無い項目は「未記載」「未検証」とする。
4. 元の4種類のYAMLスキーマは異なる。パーサー/変換処理で読み替えても元ファイルは変更しない。`verified_page`、`verified_search`、`page_verified`、`verified: true`は異なる粒度であり一律に「実機検証済み」にしない。
5. 外部教材本文は転載しない。内部ページには学習目的、範囲、リンク、案件固有補足、確認問題だけを置く。
6. 理解度確認問題は各ガイドから再利用し、答えがある場合は折りたたみ等で提示する。回答がない場合は捏造しない。
7. `integration_exercise.md`を3日目の最後に配置する。
8. 外部サイトへのアクセス、製品CLIの実行、AWSリソース作成、GitLab pushを初期研修の必須条件にしない。

## 金融用語の厳守
- **PE = 想定元本×掛目**（案件固有の略称）。簡便方式の与信残高は**CE+PE**。
- シミュレーション**PFE**は将来エクスポージャー分布の所定分位点。信頼水準・補間規則・時間軸は未確定。
- **CVA**はEEやデフォルト確率・損失率・割引などを用いる価値調整。PFE分位点そのものを単純にCVAへ投入する説明は避ける。
- BISのPeak Exposure（PEと略す場合あり）、SA-CCRのPFEアドオン、旧CEMの掛目アドオンを混同しない。旧方式を現行規制の一般式と断定しない。

## 推奨ポータル構成

- 1日目: Python, Web API, FastAPI
